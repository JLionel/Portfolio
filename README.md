# Portfolio
Portfolio to present my projects and myself.

# Context
Starting with the App Router Next.js tuto, I adapted it to work with an ASP.NET backend whilst keeping Next.js 
solely as the frontend.  
It's deployed on a free Oracle Cloud server (Ubuntu Image), with Docker containers behind an nginx proxy with certbot.

### Objective
Learn different aspect of web development and deployment.
    - Learn Next.js with tailwindcss
    - Learn ASP.NET Core api
    - Learn Docker 
    - Learn nginx

### Main technology used
- Next.js : 16.2.6
- ASp.NET Core : .NET 10.0
- EF Core
- Docker
- nginx
